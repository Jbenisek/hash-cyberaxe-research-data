# Research data instructions

Read README.md, ASSETS.json and CELLBOOK_SUMMARY.json first. Verify downloaded ZIPs with verify_release.py before analysis. Use list_cells.py for bounded inspection. Preserve record IDs, protocols, explicit target rounds, source appearances, historical statuses and publication holds. The data are published projections, not private raw snapshots. Do not equate solver labels, repeated source snapshots, witness replay, measured rates and proved attack prices. Record input hashes in derived reports.
